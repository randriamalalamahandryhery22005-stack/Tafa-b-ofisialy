TAFA V1.1.7.2 — NOTIFICATIONS AVANCÉES

Base exacte: V1.1.7.1 Commentaires avancés.

Cette version renforce l'affichage et la navigation des notifications sans
modifier le schéma Supabase ni les données existantes.

Ajouts:
- Libellés: J'aime, Commentaire, Réponse, Amitié, Message.
- Cible notification: publication/commentaire/profil.
- État non-lue conservé.
- Texte long avec retour à la ligne.
- Navigation vers le contenu quand l'identifiant correspondant est présent.
- Compatible avec les champs existants post_id, actor_id, type et comment_id.

Aucun SQL supplémentaire n'est requis pour cette version frontend.
