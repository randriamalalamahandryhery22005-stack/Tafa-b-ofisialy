# Tafa V1.1.6.18 — Final Cleanup & Performance

This release is based on V1.1.6.16 and is intended for a non-destructive final audit.

Checklist:
- Supabase Auth remains the single session source.
- Avoid duplicate realtime subscriptions/listeners.
- Avoid duplicate message/notification rendering.
- Keep Videos and Reels separated.
- Keep Marketplace search values normalized to strings.
- Preserve existing RLS/Storage policies.
- Avoid destructive schema/data changes.
- Verify loading, empty and error states.
- Verify mobile layout and media aspect-ratio behavior.
- Verify logout/login account isolation.

No database schema or user data is modified by this checklist.
