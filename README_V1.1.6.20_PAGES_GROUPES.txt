TAFAß V1.1.6.20 — PAGES & GROUPES

Cette version améliore les espaces Pages et Groupes à partir de V1.1.6.19.1.

PAGES
- Mes Pages / Découvrir
- Recherche de Pages
- Ouvrir une Page
- Suivre / ne plus suivre
- Mode Page
- Publication locale au nom de la Page
- Photos / Vidéos / Reels de Page
- Informations et statistiques de Page
- Modification de Page

GROUPES
- Tous / Mes groupes / Publics / Privés
- Recherche de groupes
- Créer un groupe
- Modifier un groupe
- Rejoindre / quitter un groupe
- Page détail du groupe
- Membres
- À propos
- Publication dans un groupe
- Visibilité des publications selon la confidentialité du groupe

UI
- Interface mobile responsive
- Cartes plus propres et compactes
- Couvertures et identité mieux structurées
- Actions adaptées au propriétaire/membre

NOTE
Les Pages et Groupes restent dans le modèle local actuel de cette application, car le schéma Supabase actuellement vérifié ne contient pas de tables public.pages ou public.groups.
Aucune nouvelle table Supabase n'est créée par cette version.
